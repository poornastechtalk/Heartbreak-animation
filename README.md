# 💔 Python Heartbreak Animation

An emotional text-based heart animation created using Python Turtle and Tkinter Canvas.

## Project Overview

This project transforms meaningful emotional phrases into a beautiful heart-shaped design. The animation gradually builds the heart, reveals a dramatic crack through its centre, separates the two halves, and finally releases the words through a falling animation.

## Features

- ❤️ Heart formation using meaningful text
- 💌 Emotional phrases in multiple languages
- 💔 Animated crack through the centre
- 🥀 Two halves gradually separating
- 🍂 Falling and fading text effects
- 🎨 Dynamic crimson and cool-tone colour transitions
- ✨ Animated glowing and heartbeat effects
- 🔄 Automatic animation restart

## Technologies Used

- Python
- Turtle Graphics
- Tkinter Canvas
- Math Module
- Random Module

## Requirements

- Python 3
- Tkinter support

No additional third-party packages are required.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python heartbreak_animation.py
```

4. Watch the heart form, crack, split, and break apart.
